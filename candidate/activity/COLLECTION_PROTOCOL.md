# 待人工执行的独立活动证据协议 v1

本任务未启动采集。须另获明确手机采集授权；只提供协议。自动识别不阻挡手选场景推荐。

每次完整会话 3 分钟，只做一个已声明条件。四个主条件为静坐×手持、静坐×口袋、步行×手持、步行×口袋；另设坐着摆手机、站立晃腿/晃口袋、乘车振动等非步行扰动条件，危险条件不安排。每条件至少 3 个全新测试会话，不能把同一会话重复切窗当独立样本。测试会话分布至少 3 个测试日期；开发、验证、测试按完整日期分配且互斥。建议先单独开发日、验证日，再预先列出三个测试日，登记日期与会话 ID 后封存清单；未预登记不得纳入测试。测试数据到齐一次评估，不调参后重用。

由现场人工记录真实活动和手机位置的开始/结束与任何转换，采用可与传感器单调时钟对齐的同步标记。保留同步误差界和原始记录供独立核查；手动发送活动文字不是独立真值。采集前后各做同步标记，无法对齐或误差 > 1 秒的会话标无可验证真值，不补猜。现场记录与传感器数据分别封存并算 SHA256，推断阶段不可读取标注、文件名、位置或未来样本。

窗口以会话 start 为锚，t=start+k秒，使用 (max(start,t-4秒),t] 内数据；前4秒弃判。只使用 timestamp、received、available 均不晚于 t 的数据。训练/验证/测试不共享会话、日期或重叠窗口。主指标只评分完整有参照的静坐/步行×手持/口袋窗口；参考转换边界 b 落在 (窗口左边界-2秒,t+2秒] 时排除。排除数和原因独立报告，算法弃判不得排除。非步行扰动另表统计 walking 误报，不混成静坐真值。

按完整会话报告 confusion matrix、precision/recall/F1、可评分预测覆盖/弃判、误报。recall 分母含全部该类合格真值窗口及弃判。precision 无预测正例时为 null。延迟从同步人工活动开始算到第一个正确输出，未检出作为删失并报告删失率；不把未检出设0秒。95%区间按完整会话 bootstrap，不能把重叠窗口当独立观测；小样本区间须注明不稳定。

手持与口袋分别核验 walking precision≥90%、recall≥80%、可评分预测覆盖≥80%，并与同一会话基线比较非步行误报。每条件新独立测试会话不足3、同步不可靠、无扰动证据或阈值未过均不替换基线。静止不得解释为学习/休息。SDK 分数即便未来获得也须作为未校准原分数保留。
