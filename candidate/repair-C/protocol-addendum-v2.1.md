# Protocol v2.1 review amendment
Original protocol-schema.md remains unchanged. Training now includes the unmodified production EvidenceStore export bundle (snapshots/exposures/events/sessions). learner.store.validate_bundle verifies exposure-target uniqueness, hashes, content identities and causal time chain; its sorted event output is exactly compared to source-backed labels. Eligibility and development digest use those validated events, matching production model.train. No model fitting is performed.
Model remains compatible with production model.train output. fit_event_ids and created_at live in source-backed training.model_record with model_hash, not mandatory new model fields. Synthetic fixture model is marked synthetic and cannot be used as real training evidence. Source data and model record must all match.
All content identifiers use sha256:64 lowercase hex. Each trial session includes independent_unit, disjoint from development and training unit identities even if session names differ. Repeated exposure+target cannot inflate training eligibility. Session means use lexicographically sorted session IDs so seeded bootstrap is invariant to input row order.
