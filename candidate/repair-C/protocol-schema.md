# Benefit evidence protocol v2 (frozen before implementation)
API remains pilot_metrics(rows, plan). Missing or invalid evidence yields NO_USER_BENEFIT_EVIDENCE with ordered reason codes; no exception is used as validation.
Constants unchanged: seed 20261004; 6 exposures per policy per session; paired bootstrap 10000; planning >=6 development session differences and ceil(max(12,(1.96+.841621)^2*sample_variance/.10^2)/.8); missing <=.20; mean gain >=.10; gain and worst-missing lower >0; interruption upper <=0.
plan has status FROZEN, evidence_kind synthetic|real_user, sessions, session_ids (ordered), seed, frozen_at, collected_until, development_data_hash, paired_session_variance, schedule, versions (request_hash/library_hash/feature_hash/initial_preferences_hash), and evidence.
evidence contains source artifacts (id, payload, sha256), development (sessions and raw per-policy rows), training (completed sessions, source-backed labels), model (production-compatible manifest, weights/transform and digests), predictions, snapshots, exposures, feedback, session_records and registration.
All objects with sha256 use canonical UTF-8 JSON sorted keys, compact separators, no NaN. Artifact source payloads carry kind, evidence_kind, collector, and exact data object. They bind their record contents independently of caller status/provenance strings. source_id links are unique and checked; artifact bytes must match sha256. This validates recorded integrity and consistency, not external human authenticity; that still requires trustworthy collection and independent audit.
Development rows retain exposure, content, session, policy, accept/null and exposed_at/recorded_at, source_id. Complete independent development sessions have source-backed boundaries; at least six paired-session P2-P0 means, all records end before freeze, no development/trial or training/trial session overlap. Counts/differences/variance/N are recomputed, never accepted from claimed scalar summaries.
Training labels carry event_id, session_id, content_id, target, value, recorded_at, feature_hash and source_id. Song split is recomputed from content_id and frozen seed. >=40 nonsealed labels, >=10/class, >=5 completed independent sessions; dev >=30, >=8/class, >=4 sessions. No sealed fit; exact development IDs/hash and complete training bundle hash bind the model. Model fixed params/version/seed, finite 63 weights/3-component transforms, feature hash and creation time are checked before registration.
Registration is a source artifact binding the complete plan core, ordered trial IDs, fixed N, recomputed variance, development/model hashes, schedule, version hashes and frozen timestamp. Schedule must equal the deterministic six-permutation sequence. Every frozen session must be present exactly once with source-backed start/completion; no optional stopping or session deletion.
Prediction record: prediction_id, session_id, content_id, policy, effective_policy, predicted_at, model_hash (P2), versions, state_id, prior_feedback_ids, source_id. Policies have distinct state IDs per session, share initial preferences, and update from all/only their earlier feedback in that session.
Snapshot: snapshot_id, prediction_id, prediction_hash, created_at, versions, sha256 (digest excluding sha256). Exposure: exposure_id, snapshot_id, snapshot_hash, session_id, content_id, policy, effective_policy, exposed_at, source_id. Feedback: event_id, exposure_id, target=scenario_acceptance, value/null, interruption/null, skipped/null, recorded_at, source_id. Each source backs exact record excluding source_id.
Prediction <= snapshot <= exposure <= feedback <= collected_until; all trial events follow registration and fit inside source-backed session boundaries. Snapshot versions match prediction and plan. No orphan or duplicate nodes; row set exactly matches exposures, row references/labels/versions match graph; no repeated content within session and actual block order matches schedule, six exposures each. Missing feedback stays null, never negative.
Synthetic source artifacts cannot be promoted by changing provenance: plan and EVERY artifact must agree. Valid synthetic protocol plus numerical pass returns SYNTHETIC_TEST_PROTOCOL_SUPPORTED, mechanism_pass true, real_benefit_supported false. Real sources passing all integrity/protocol/numerical gates may return PILOT_BENEFIT_SUPPORTED, with scope limited to this user/scenarios and nonblinding declared.
Boundary tests exercise gate helper independently so unrelated failures cannot hide exact N, .20 missing, .10 gain, strict positive lower bounds and nonpositive interruption upper. Independent test reference reconstructs means and bootstrap from recorded rows.
